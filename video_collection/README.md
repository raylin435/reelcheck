# Short-video fact-checking collection

The [50-case evidence-backed development set](benchmark50/README.md) includes
separate verifier inputs, provisional reference labels, provenance, source snapshots,
and a human review template. Its AI-drafted labels have not been human-verified.

For the Fireworks multi-model labeling pipeline, see [LABELING.md](LABELING.md).
For the reduced-token 300-video run, see [BULK_LABELING.md](BULK_LABELING.md).

**Current completed run (2026-11-02): 300 downloaded and labeled videos, spanning ten categories and 49 creators.** The ready-to-load manifest is `data/bulk/dataset.jsonl`. Fourteen audited pilot records were reused; 286 videos received two compact independent model judgments. All labels remain machine-generated and provisional: 186 abstain. The full 1,000-video queue has not been downloaded. The earlier pilot description below records the collection's starting point.

Collect public videos with `yt-dlp`, retain provenance, and build a claim-level evaluation set. The source roster covers 50 posters in ten topic groups: world news; politics and society; medicine; food and fitness; science and space; climate; finance; technology and AI; history and geography; and streamer commentary.

**Downloaded clips are research candidates, not automatically verified examples.** Channel selection is a sampling decision, never a factual verdict about a creator. Topic and English-language eligibility need review too.

Verified on 2026-11-02: **3,312 unique YouTube candidates from 47 active channels**, **70 original-video leads from 41 fact-check articles**, and a **1,000-item queue** (950 broad samples, 50 evidence leads). The pilot produced **22 playable files across all ten sampling groups**, totaling 52.7 MB; one TikTok extraction failed. All 22 files passed full FFmpeg decoding. All factual labels remain unreviewed. The complete 1,000-file batch has **not** been downloaded; the commands below resume from the pilot. Three target channels had no Shorts tab: Just Have a Think, History Hit and Asmongold TV.

## Run

Python 3.11+ and Node 22+ are needed. FFmpeg is supplied locally by `imageio-ffmpeg`; no global installation or API key is required.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python collect.py discover --per-source 80
.venv/bin/python factcheck_seeds.py
.venv/bin/python collect.py select --count 1000 --factcheck-count 50
.venv/bin/python collect.py download --limit 1000
.venv/bin/python collect.py report
```

Run these commands from this repository. Discovery and completed downloads resume from local files. `--refresh` refreshes channel discovery. `download --limit` limits new attempts, not successful downloads: deleted, unavailable, or out-of-range clips can make the final count smaller. To replenish failures, select a larger pool (for example `select --count 1400`) and rerun downloads with the number of additional attempts desired. Re-selection is deterministic for a fixed source snapshot and seed, but expanding it can alter the selected subset.

For a small pilot, use `download --limit 20`. For original-video leads only, use `download --manifest data/factcheck_candidates.jsonl --limit 20`. Five consecutive failures stop a run so it does not keep hammering a blocked platform. Check `data/downloads.jsonl` before retrying; private, removed, login-gated and rate-limited items remain failures. The scripts do not use browser cookies or proxies. Allow a few hours for a sequential 1,000-clip run; timing and size vary by clip, format and platform response.

YouTube discovery and direct downloads have been tested here. TikTok and Instagram URLs are accepted by the same downloader, but their availability is assessed per clip. The broad sample therefore uses YouTube; the evidence-led sample can cross platforms.

The downloader accepts 10–180 second clips, checks the declared duration, then decodes the entire file with FFmpeg. It keeps a SHA-256 hash and records failures. It targets 480-pixel video height for a small collection footprint; the fallback can exceed that resolution if lower formats are unavailable. For small on-screen text, recollect at higher resolution before evaluating OCR or visual reasoning. Estimated storage should be based on the pilot's actual bytes per minute, not an assumed platform bitrate.

## Getting good and bad factual information

Use two complementary routes:

1. **Broad collection:** newsroom reporting, independent journalists, educational creators, health/finance vloggers and streamer commentary. This supplies natural variation, including correct claims, disputed claims and opinions. There is no automatic truth label based on publisher identity.
2. **Evidence-led collection:** collect the original videos linked in fact-check articles. `factcheck_seeds.py` retrieves the five-page Full Fact TikTok archive and extracts YouTube, TikTok and Instagram video URLs. A link may be the false claim, a rebuttal, or authentic reference footage: review its role before labeling. An article's verdict must never be copied onto every linked video.

For the final 1,000 reviewed clips, an illustrative target is 400 supported, 400 refuted/misleading, 100 mixed and 100 insufficient-evidence/not-checkable. These are annotation targets, **not achieved class counts**. Collect additional candidates until quotas are filled, and report each class separately. Preserve a naturally sampled slice too: a balanced benchmark does not estimate real-world misinformation prevalence.

Full Fact's [investigation of apparent academic impersonations](https://fullfact.org/health/academics-deepfaked-tiktok-wellness-nest/) links two downloadable Shorts, IDs `nPg--LTa31w` (92 seconds) and `W7kMp7eDGVA` (125 seconds). Both were successfully downloaded in the initial pilot. The investigation concerns apparent fabricated endorsements; it explicitly does not evaluate all underlying health claims. Keep that distinction in annotation. Files are in `data/videos/`, prefixed `youtube_`.

Expand false-claim leads using [AFP Fact Check](https://factcheck.afp.com/), [PolitiFact's TikTok archive](https://www.politifact.com/personalities/tiktok-posts/), [Snopes](https://www.snopes.com/), and [Full Fact](https://fullfact.org/tiktok/). Find original links and search for the exact claim/event across platforms. Record unavailable originals as attrition; substituting a debunking clip changes the task.

## Annotation and evaluation

Watch each clip with audio. Extract timestamped atomic assertions from speech, visible text, visuals, and their combination. Mark whether the speaker asserts, quotes, disputes, or jokes about each claim. Verify the date, location, entities and source footage against primary evidence. Use two independent reviewers and adjudicate disagreements; leave genuinely unresolved claims unresolved. Human review of language and topic is required because channel labels are only sampling buckets.

Keep annotations and fact-check URLs outside the model input. A debunk's title, publisher identity, or collection route can otherwise reveal the label. Supply the same video, caption policy, tools and retrieval budget to the baseline and harness. Track claim extraction, macro-F1 by verdict, evidence correctness, abstention, latency and cost. Report uncertainty rather than claiming a small aggregate difference proves superiority.

Deduplicate exact files with hashes; also review reposts, excerpts and near-duplicates using visual similarity and transcript overlap. Split by event/claim cluster so versions of the same hoax never cross train and test; add a creator-held-out test to detect publisher shortcuts. A suggested 600/200/200 split is made only after clustering. Use a fresh temporal holdout for testing beyond already-public fact-checks, since known benchmarks and public debunks may have appeared in model training.

## Existing datasets worth using

- [FakeTT / FakingRecipe (official)](https://github.com/ICTMCG/FakingRecipe): 1,991 English TikTok videos under three minutes, comprising 1,172 fake and 819 real examples across 286 events. Access requires an application; it is not an immediate unrestricted download. Useful as an external comparison set if access arrives.
- [FakeSV (official)](https://github.com/ICTMCG/FakeSV): Chinese short-video IDs and annotations are published; data use requires an agreement. Not the default English collection.
- [InVID Fake Video Corpus](https://zenodo.org/records/2535479): an older annotated corpus of real/fake videos and reposts. Inspect the archive contents and current URL availability before assuming the small metadata download contains media.

The immediate collection route is independent of these applications. Public accessibility does not grant redistribution rights: keep source attribution and recorded license fields, and share URL/annotation manifests unless media reuse is authorized.

Implementation reference: [official yt-dlp documentation](https://github.com/yt-dlp/yt-dlp) and [JavaScript runtime setup](https://github.com/yt-dlp/yt-dlp/wiki/EJS).
