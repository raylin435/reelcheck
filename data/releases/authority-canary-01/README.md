# Authority development canary — recorded results

Four development cases; no held-out candidate inference. Five arms include a memory-only diagnostic and a metadata-only ablation. Reference-label matching is provisional; grounding is separately assessed by two models. No human-verified accuracy or aggregate harness advantage is established.

`summary.json` retains failures and unresolved outcomes. `traces.json` preserves all initial and final attempts, exact metadata checks, selected tool actions, source URLs/hashes, and judgments. Full page text, raw web caches and API request bodies stay local. `source_hashes.json` pins the executed sources; `config.json` records models and token rates. Assessment completion files report actual known cost separately from candidate cost. Web billing is unavailable.
