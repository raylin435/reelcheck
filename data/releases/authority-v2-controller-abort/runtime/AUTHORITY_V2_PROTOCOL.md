# Authority v2 — formatting fix and larger comparison

Predeclared before v2 candidate inference. The v1 canary and its runtime remain unchanged.

## Equal deterministic output boundary

Every arm selects numbered spans from its own opened pages. The controller copies the original input claim and the exact selected span text; it never selects evidence, changes a verdict, changes a date, or repairs a semantic assertion. Reader-generated link wrappers are removed while their visible text is retained, with both page hashes and raw web responses recorded. Unknown span IDs and wrong-page metadata spans remain errors. The same rendering is applied to ordinary retry, metadata enforcement, targeted recovery, reference model and the memory diagnostic. Therefore, any drop in copying errors is a shared infrastructure fix, not a treatment advantage. Quotes may include the whole selected paragraph; exact matching does not prove entailment.

## References before inference

Two blind machine reviews per case receive freshly retrieved full primary-source page text, dated claim and source URL, without the proposed label or candidate answers. All 40 cases are reviewed, including the four previously reviewed with shorter excerpts. Review records and source hashes are retained. Matching independent verdicts/reasons with high confidence become `machine_consensus` reference keys. If both reviewers agree on a correction, record the before/after key and freeze the correction before candidate inference. Reviewer quotations that are not verbatim are retained as such and receive a separate span-ID anchoring pass; this does not overwrite the first review. Any disagreement, open-world ambiguity, failed review or unsupported quotation after anchoring remains `unresolved`; do not discard the case or silently score it as true. Unresolved references remain in denominators with an explicit unknown result. This is machine review, not human or clinical validation.

## Larger experiment

Retain the original 20 development / 20 held-out split and all 20 document families. No candidate sees reference files, their source URLs or review labels. The full 20-case development comparison has five arms (memory, ordinary retry, authority recovery, metadata-only, stronger open reference). The 20 held-out cases have four arms (omit the development-only metadata ablation). Run the held-out set after development execution and integrity checks, with exactly the same frozen implementation, prompts, models, budgets and reviewed references. Do not tune between partitions based on outcomes. A transport or model failure stays a failure; no hidden retry or favorable rerun.

Each partition uses four fixed index-modulo shards of five claims. Shards are execution units only; original document-family split remains intact. Cheap-arm branch order rotates deterministically by case ID. Each initial draft has one search, two reads, five calls; each fork has one extra search, two reads, five calls. No search is supplied with a reference answer. The reference model has the same research allowances. Configured conservative ceilings are $2 candidate and $5 grounding reservations per shard (eight shards total), plus $8 for the blind reference-review batch and $2 for separately recorded reviewer citation anchoring. These are upper reservations, not expected spend; report actual known token estimates and unknown web costs.

Promotion to held-out inference requires a completed development execution with passing integrity checks and no unresolved implementation or transport-state corruption. It does not require a favorable treatment score. If integrity fails, diagnose and preserve the run; do not spend held-out cases under defective code. Unresolved reference labels do not block evaluation of retrieval/execution, but their truth outcomes remain unresolved across every arm.

## Metrics

Report partitions separately: provisional reference-label match, wrong decisive answers, operational abstention on answerable claims, completion, final metadata validity, two-judge grounding acceptance/disagreement/failure, actual follow-up search count, and deployment versus shared-draft-deduplicated cost. Report the four-per-partition recent-notice subset separately; only eight of all 40 notices are within 90 days. Preserve all failed attempts and unknown-cost calls. Both-completed paired semantic gains must be distinguished from format/API gains. Aggregate judge acceptance is not human-verified accuracy; one grading model shares the reference model's family. Report unresolved references and judgments without forcing a winner. Claim preservation and quote fidelity produced by the renderer are not evidence of model reasoning quality.
