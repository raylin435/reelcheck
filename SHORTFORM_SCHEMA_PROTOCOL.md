# Schema-matched follow-up: protocol declared before this run

Date: 2026-11-02. Exploratory comparison on the six development cases already
tested in `SHORTFORM_DEV_RESULTS.md`. This is not a fresh or held-out evaluation.
Keep the original run and its AI references unchanged. Human review remains pending.

Question: does citation-ID selection with deterministic rendering add observable
value beyond ordinary JSON-schema output where GPT-OSS writes its own quotations?

## Two systems

`gptoss_schema_quotes`: GPT-OSS 120B, original direct prompt B and a five-field
JSON schema. The schema constrains field types, verdict/reason choices and passage
IDs to supplied IDs. Claim text and quote strings are generated by the model; the
schema contains neither the original claim nor source text. No repairs or rendering.
The ordinary post-generation validator checks exact claim preservation and quotes.

`gptoss_citation_ids`: unchanged four-field citation-ID schema and prompt from the
earlier experiment. The renderer copies the original claim and selected passages.
It preserves the model's verdict, uncertainty reason and explanation.

Both use Fireworks `json_schema`, the same GPT-OSS model, default sampling settings,
4096 output-token ceiling, six identical fixed evidence packets and the same frozen
reference artifact. [Fireworks documents that schema mode disables reasoning
output](https://docs.fireworks.ai/structured-responses/structured-response-formatting).
The citation representation, prompt contract and generation length still differ:
this compares two practical configurations, not a pure renderer-only intervention.

## Execution and analysis

One batch of 12 generation calls, shuffled system order within case (seed 2026),
two workers, no retries, prompt tuning or selective reruns. Generation reservation
cap $1. Kimi K3 with high reasoning effort judges valid outputs against the unchanged
frozen AI references; judge reservation cap $2, at most 12 calls. Both caps are local
conservative estimates, not provider billing guarantees. No extra deployment.
